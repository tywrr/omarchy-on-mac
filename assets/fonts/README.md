# Cheatsheet fonts

These are the same open-source fonts used by the local Herdr keyboard wall sheet.
They are embedded in the generated PDF and included here for reproducible builds.

| Inter-Regular.ttf, Inter-SemiBold.ttf | [Inter](https://github.com/rsms/inter) | inter-OFL.txt |
| JetBrainsMono-Regular.ttf | [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) | jetbrainsmono-OFL.txt |

License text was retrieved from the corresponding Google Fonts `ofl` directory.
